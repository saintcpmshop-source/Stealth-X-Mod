## 🛠️ Step-by-Step Installation

### Step 1 — Backup Your Account

Before uninstalling the original game:
- Open Car Parking Multiplayer → **Settings** → **Account** → **Link Account**
- Note down your login (Google/Facebook)
- Or screenshot your current progress

### Step 2 — Enable Unknown Sources

1. Open **Settings** on your device
2. Navigate to **Security** (or **Apps → Special Access**)
3. Enable **Install from Unknown Sources** / **Install Unknown Apps**
4. Allow it for your browser or file manager

### Step 3 — Uninstall the Original Game

> ⚠️ **Critical:** You cannot have both versions installed. Uninstall the original Car Parking Multiplayer first.

1. Long-press the CPM icon
2. Tap **Uninstall**
3. Confirm

### Step 4 — Install Stealth X

1. Open your file manager
2. Navigate to your **Downloads** folder
3. Tap `StealthX-v4.9.10.apk`
4. Tap **Install**
5. Wait for the installation to finish
6. Tap **Open**

### Step 5 — First Launch

1. Launch **Stealth X**
2. Log in with a **guest account** first (safer than linking main account)
3. Open the **Mod Menu** (floating purple icon) and verify features are active
4. Check the car list for the 16 MOD vehicles
5. **Restart the app once** for all changes to apply
