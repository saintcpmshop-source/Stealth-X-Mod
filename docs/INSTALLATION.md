## 🛠️ Step-by-Step Installation

### Step 1 — Backup Your Account

Before uninstalling the original game:
- Open Car Parking Multiplayer → **Settings** → **Account** → **Link Account**
- Note down your login (Google/Facebook)
- Or screenshot your current progress

### Step 2 — Enable Unknown Sources

1. Open **Settings** on your device
2. Navigate to **Security** (or **Apps → Special Access**)
3. Enable **Install from Unknown Sources** / **Install Unknown Apps**
4. Allow it for your browser or file manager

### Step 3 — Uninstall the Original Game

> ⚠️ **Critical:** You cannot have both versions installed. Uninstall the original Car Parking Multiplayer first.

1. Long-press the CPM icon
2. Tap **Uninstall**
3. Confirm

### Step 4 — Install Stealth X

1. Open your file manager
2. Navigate to your **Downloads** folder
3. Tap `StealthX-v4.9.10.apk`
4. Tap **Install**
5. Wait for the installation to finish
6. Tap **Open**

### Step 5 — First Launch

1. Launch **Stealth X**
2. Log in with a **guest account** first (safer than linking main account)
3. Open the **Mod Menu** (floating purple icon) and verify features are active
4. Check the car list for the 16 MOD vehicles
5. **Restart the app once** for all changes to apply

## 🐛 Troubleshooting

### ❌ "App not installed"
- **Cause:** Original game is still installed
- **Fix:** Uninstall the original game completely, then retry

### ❌ "Parse error"
- **Cause:** Corrupted APK download
- **Fix:** Re-download the APK from Releases

### ❌ App crashes on launch
- **Cause:** Cache conflict or low storage
- **Fix:**
  1. Clear app cache: Settings → Apps → Stealth X → Storage → Clear Cache
  2. Free up at least 1 GB of storage
  3. Restart device

### ❌ "No money showing"
- **Cause:** Mod needs one full cycle to apply
- **Fix:** Buy any cheap car → close app → reopen

### ❌ "Install blocked"
- **Cause:** Play Protect or antivirus
- **Fix:** Temporarily disable Play Protect in Play Store → Settings

### ❌ Multiplayer not working
- **Cause:** Server-side detection or version mismatch
- **Fix:** Use offline mode only for safest experience

## 🔄 Updating

When a new version is released:

1. **Do not uninstall** the current version
2. Download the new APK from [Releases](https://github.com/saintcpmshop-source/stealth-x-mod/releases)
3. Install it over the top (**don't** uninstall first, or you'll lose data)
4. If signature mismatch occurs, uninstall & reinstall (data will be lost)

## 🗑️ Uninstallation

1. Long-press Stealth X → **Uninstall**
2. If you want to return to the official game:
   - Install Car Parking Multiplayer from Google Play
   - Log in with your original account
