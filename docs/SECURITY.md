## 🚨 Reporting a Vulnerability

**Please do NOT** report security issues via public issues.

### How to Report

1. Open a **private security advisory** on GitHub:
   - Go to the **Security** tab → **Advisories** → **Report a vulnerability**
2. Or contact the maintainers privately

### What to Include

- **Description** of the issue
- **Steps to reproduce**
- **Potential impact**
- **Suggested fix** (if any)
- **Your contact info** (optional)

## 🔍 Scope

### In Scope

- Malicious code in the mod
- Data leakage
- Unauthorized access
- Signature forging
- Fake APK impersonation

### Out of Scope

- Account bans from the original game
- Game balance issues
- Feature requests
- Online cheating detection

---

## ⚠️ Safety Best Practices for Users

| Practice | Why |
|:---|:---|
| **Verify APK checksums** | Ensures file integrity |
| **Download from official Releases** | Avoids fake APKs |
| **Don't share your account** | Prevents theft |
| **Play offline** | Safer from detection |
| **Use a throwaway account** | Protects main account |

---

## 🚨 Known Risks

- **Online play** may trigger detection
- **Third-party downloads** may be malicious
- **No mod is 100% undetectable**
