## 🐛 Report a Bug

If you found a bug:

1. **Search existing issues** first — it may already be reported
2. Make sure you're on the **latest version** (v4.9.10)
3. Open a **new issue** with:
   - Device model
   - Android version
   - Stealth X version
   - Steps to reproduce
   - Screenshots if possible

## ✨ Suggest a Feature
