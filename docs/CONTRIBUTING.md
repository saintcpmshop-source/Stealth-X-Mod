## 📋 Ways to Contribute

| Type | How |
|:---|:---|
| 🐛 **Bug report** | Open an Issue with the bug template |
| ✨ **Feature request** | Open an Issue with the feature template |
| 📝 **Documentation** | Submit a Pull Request to `docs/` |
| 🌍 **Translation** | Help translate docs |
| 🧪 **Testing** | Test new builds and report results |

---

## 🐛 Reporting Bugs

Before opening an issue, please:

1. **Search existing issues** — it may already be reported
2. **Update to the latest version** (v4.9.10)
3. **Reproduce the bug** at least twice
4. **Gather info:**
   - Device model
   - Android version
   - Stealth X version
   - Steps to reproduce
   - Screenshots/video if possible
   - Logcat output if available

> ⚠️ **Do not** report bugs caused by other mods or by playing online.

---

## ✨ Suggesting Features

Open an Issue with:
- **Title:** `[Feature] Short description`
- **What:** What you want added
- **Why:** Why it would improve Stealth X
- **How:** Any implementation ideas

## 🔧 Pull Requests

### Workflow

```bash
# 1. Fork the repo
# 2. Clone your fork
git clone https://github.com/YOUR-USERNAME/stealth-x-mod.git
cd stealth-x-mod

# 3. Create a branch
git checkout -b feature/your-feature-name

# 4. Make changes
# 5. Commit
git add .
git commit -m "feat: add your feature description"

# 6. Push
git push origin feature/your-feature-name

# 7. Open a Pull Request
